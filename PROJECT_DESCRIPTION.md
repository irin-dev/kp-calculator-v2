# Описание проекта — Калькулятор коммерческих предложений (КП)

## 1. Задача

Небольшие IT-студии и фрилансеры считают стоимость разработки чат-ботов «вручную»: опрашивают клиента в переписке, собирают требования из сообщений, а потом долго пересчитывают цену под каждый вариант. Это медленно (переговоры растягиваются на дни), ошибочно (легко забыть множитель за платформу или интеграцию) и отпугивает клиентов из-за неопределённости.

**Задача:** заменить ручной расчёт инструментом, который за 2 минуты проводит клиента по короткой воронке вопросов и выдаёт вилку стоимости + готовое КП — в одном веб-приложении.

## 2. Решение

Веб-калькулятор: 7–9 вопросов, один на экран → профиль проекта → расчёт по формуле → вилка цены → КП в HTML/PDF.

Два контура:
- **Бот под ключ** — квиз с ветвлением (сценарный / AI / гибрид), собирает характеристики будущего бота.
- **Готовый продукт** — тарифная витрина с фиксированными ценами (коробочные решения).

## 3. Пользователи

- **Студия (внутренний инструмент):** быстро получает профиль клиента и вилку цены для переговоров.
- **Клиент:** за 2 минуты видит ориентир бюджета без долгих созвонов.

## 4. Основные функции

- Воронка «один вопрос на экран» с кнопкой «Назад» и восстановлением сессии (`localStorage`)
- Ветвление: сценарный / AI / гибрид → разные наборы вопросов
- Мягкие выходы: «до 30к», «просто интересуюсь» → корректный отказ без потери контакта
- Экран «договоримся по звонку» для сложных сценариев
- Формула расчёта с вилкой 0.9×–1.3× (сервер, единый источник правды)
- Встраивание реквизитов в шапку КП из `.env` (без хардкода)
- КП в HTML с печатью в PDF

## 5. Результат на выходе

Профиль клиента (ответы квиза) → вилка стоимости → КП с реквизитами исполнителя, готовое к отправке.

## 6. Технологии

Python 3 (стандартная библиотека: `http.server`, без внешних зависимостей), JSON-конфиг квиза, Vanilla JS/CSS, pytest (28 тестов).

## 7. Как запустить

```bash
python src/app.py        # → http://127.0.0.1:8000
python -m pytest tests/test_calculator.py -v
```

## 8. Расчётная формула

```
КП = (База × Платформа + Σ(интеграции) + Модуль_AI + Админка) × Срочность
```

Вилка 0.9×–1.3× вместо точной цены — осознанное продуктовое решение (оставляет место для торговли и не фиксирует цену до созвона).

# Скилл: Калькулятор КП

Генерация, изменение и тестирование калькулятора коммерческих предложений (квиз → вилка стоимости → КП в HTML/PDF).

## Запуск

```bash
python src/app.py
# → http://127.0.0.1:8000
```

## Тесты

```bash
pip install pytest
python -m pytest tests/test_calculator.py -v
```

## Единый источник правды

Числа и ветвление живут ТОЛЬКО в `data/quiz.json` и `src/calculator.py`. Фронтенд (`static/main.js`) не дублирует формулу — он шлёт ответы на `POST /api/estimate` и показывает то, что вернул сервер. Правь данные в `quiz.json`, логику — в `calculator.py`, вёрстку — в `static/`.

## Как изменить воронку

1. Открой `data/quiz.json`, найди блок `screens` (экраны):
   - `id` — уникален, используется для переходов и состояния квиза
   - `type`: `single` (один выбор) / `multi` (несколько) / `contact` (контакты)
   - `options[]` — варианты; `weight` ссылается на ключ блока `weights`, `next` — переход, `overrides` — вынужденное ветвление
2. `weights` — базовые цены и множители. `rules` — пороги (напр. минимум «не знаю» до созвона).
3. `soft_exits` — мягкие выходы для сценариев «до 30к» и «просто интересуюсь».
4. `ready` — блок «готовых продуктов» с фиксированными тарифами.
5. После правок: `pytest` зелёный + smoke-прогон (см. README, таблица «Ручная проверка»).

## Регресс

После любого изменения `quiz.json`/`calculator.py` прогнать:
- `python -m pytest tests/test_calculator.py -v` — 28 тестов
- вручную: сценарный → вилка; AI → вилка; «до 30к»+AI → мягкий выход; «гибрид» → созвон; «готовый продукт» → фикс.цена; перезагрузка страницы → восстановление вопроса; «Назад» на каждом шаге
